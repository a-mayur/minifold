# Security policy

## Supported versions

Only the latest release gets security fixes. Please update before reporting.

## Reporting a problem

Please **don't open a public issue** for security problems. Report them privately instead:
go to the [Security tab](https://github.com/a-mayur/minifold/security/advisories/new) and choose **Report a vulnerability**.

Include what you found, how to reproduce it and which version you run.
